# 傳音玉符與 CSB 配套

插件啟用或升級時，會在酒館支援世界書讀寫 API 的情況下自動匯入目前版本。也可在「玉符接入 → 世界書與正則 → 重新匯入／更新配套」執行。

- `worldbook-tavern-pocket.json`：手機完整操作協定、格式實例，以及 CSB 資料更新、在場判定、手動管理和掃描原則，共 15 個條目。
- `regex-hide-phone.json`：只作用於顯示的正則，隱藏完整 `phone` 與 `CSB_UPDATE` 資料區塊。原始訊息仍供插件解析；原有狀態欄、故事文字及圖片保留。
- 檔名含版本號的兩份 JSON 與上述目前版檔案內容相同，供手動匯入或備份。

世界書固定使用「傳音玉符 · CSB 配套協定」名稱更新，只替換由插件標記的配套條目，保留另外加入的自訂條目。正則沿用插件的固定 ID，不改動其他正則。舊版本另存的世界書不會被刪除；若以前手動綁定舊配套，請停用該舊綁定，避免重複或過時指令。

內建手機及 CSB 提示已在執行時注入。世界書已匯入不代表必須全域啟用；使用內建提示時不需再綁定這本協定書。角色卡的故事世界書與原有獨立狀態欄照常保留。若酒館無法提供世界書 API，以上兩份 JSON 可在酒館「世界書」與「正則」頁面手動匯入。

正則不執行付款、發訊或角色更新，也不會繞過模型限制。自然語句的手機操作由插件的事件解析器判斷；正則不以寬鬆文字比對刪除一般敘事。
