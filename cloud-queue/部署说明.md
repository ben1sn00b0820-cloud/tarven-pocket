# 云端出图队列 · 部署说明

几个人共用一个 NovelAI 账号时，同时出图会撞车（429），太频繁还可能被风控。云端队列让大家排同一条队：前面有人在画，后面的人就等着，一张画完再轮到下一个；有人撞上 429，所有人一起等一会儿。

队列服务放在你自己的 Cloudflare 账号里，免费额度够几个朋友日常使用。它只看得到房间码、随机的排队号和“正文图片”这类简短标签，看不到 NovelAI 密钥、提示词和图片。

只需要一个人部署一次，其他朋友填同样的地址和房间码就行。

**已经有按密钥排队的队列服务（比如智绘姬用的那个）就不用部署**：在插件里把队列类型选成「按密钥排队」，填上那个地址即可。用同一个 NovelAI 密钥的人会自动排进同一条队，不需要房间码，也能和用智绘姬的朋友一起排。插件只发送密钥的 SHA-256 摘要（算不回密钥），不发送密钥本身。

## 方法一：用网页按钮部署（推荐）

1. 注册并登录 Cloudflare：https://dash.cloudflare.com/sign-up （免费）。
2. 打开这个链接：
   https://deploy.workers.cloudflare.com/?url=https://github.com/hey8v0/ST-iPhonie/tree/main/cloud-queue
3. 按页面提示授权 GitHub、确认部署。项目名保持 `st-iphonie-queue` 就好。
4. 部署完成后，页面会给出一个地址，类似 `https://st-iphonie-queue.你的名字.workers.dev`。复制它。

如果按钮页面报错，用方法二。

## 方法二：用命令行部署

需要电脑上装有 Node.js（https://nodejs.org ，装 LTS 版本）。

1. 打开终端，进入这个文件夹（插件目录下的 `cloud-queue`）。
2. 登录 Cloudflare（会打开浏览器让你确认）：
   ```
   npx wrangler login
   ```
3. 部署：
   ```
   npx wrangler deploy
   ```
4. 命令最后会打印出地址，类似 `https://st-iphonie-queue.你的名字.workers.dev`。复制它。

## 在插件里填写

1. 小手机 → 绘图 → 参数 → 排队 → 打开「云端队列」。
2. 「队列地址」填上面复制的地址。
3. 点「生成房间码」，得到一串 24 位的字母数字。
4. 点「测试连接」，显示“连接正常”就好了。
5. 把地址和房间码发给共用账号的朋友，他们在自己的插件里填同样的两项。

房间码就是这条队的门牌：知道房间码的人都能排进来，所以只发给一起用账号的人。想换一条队，重新生成房间码再发给大家即可。

## 常见问题

- **连不上队列怎么办？** 插件会照常出图，只是退回本机排队，并在排队设置里显示“连不上云端队列”。
- **会花钱吗？** Cloudflare 免费档每天有 10 万次请求。排队时每 2 秒问一次，几个人日常用远远用不完。
- **有人画到一半关掉了网页？** 他的号 2 分钟后自动作废，队伍继续往下走。
