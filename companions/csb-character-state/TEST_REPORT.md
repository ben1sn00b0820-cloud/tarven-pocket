## 主要覆蓋範圍

資料驗證包含：共用欄位新增／改名、各角色獨立值、未知與 0／false 的區別、數值上下限、負值範圍、單次變動限制、固定／手動／鎖定欄位、不完整與重複更新區塊、拒絕未知欄位、原子套用、原型污染防護與不執行資料中的程式文字。

記憶與歷史包含：離場重返、編輯／刪除／切換回覆重建、分支手動覆寫、保存後重新載入、不同聊天隔離、同名角色獨立 ID、禁止新增不抹除舊角色、政策修改不倒改已接受歷史、備份匯入起點。

遷移與橋接包含：CSB21 自訂部位、舊清潔度不轉成淫蕩值、世界書模板不誤當真實角色、備份往返、損壞匯入不修改原資料、MVU 寫入保留其他命名空間、MVU 讀回與缺少 MVU 錯誤、讀取期間切換聊天取消後續寫入。

瀏覽器實際操作包含：模擬休息更新、離場重返、表單新增 0～1000 自訂進度條、設定分段標籤與單次上限、只修改指定角色、重新載入仍保留、純文字渲染阻止 HTML 執行、響應式介面。

酒館模擬宿主驗證包含：擴充入口、提示注入、quiet 生成清除提示、swipe 生成使用前一個狀態、回覆下的收合卡片、顯示層隱藏 JSON 但原訊息保留、回覆編輯與錯誤更新。

## 實測邊界

沒有連線到使用者的手機 SillyTavern、實際模型或 MVU 實例。酒館整合採公開介面與模擬宿主驗證；MVU 採公開介面與 mock 讀寫測試。模型是否穩定輸出有效更新，仍受其能力、提示詞與其他插件影響。

可重現測試程式在 `tests/`，逐項紀錄在 `tests/unit-results.txt` 與 `tests/artifacts/ui-results.json`。
