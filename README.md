## v0.11.0：角色信息固定保存與傳音玉符

### 人物資料與正文顯示

桌面新增獨立 **角色信息** 應用。已儲存的人物欄位持續保留；新訊息省略某欄、未包含更新區塊、人物離場，或輸出未知空值，都不會清除已知資料。正文的 `<CSB_UPDATE>` 僅更新明確變動的欄位；使用者可手動編輯或清空。模型明確移除欄位時須用 `clear` 並附理由。

原手動修改綁在訊息內容雜湊與分支上，編輯／重抽後可能失效；現在改為持久修改紀錄與訊息順序邊界，舊紀錄自動遷移並保留遷移備份。分支自身的劇情變化仍隨重抽／刪除重算，避免把不同分支的支出疊加。這項修復可保留仍存在於存檔的紀錄，無法憑空還原已被刪除且沒有備份的原值。

正文內的插件卡片標題改為 **劇情狀態**，顯示該回合快照。角色信息 App 的 **正文顯示** 開關只控制可見性，關閉後資料仍保存、仍接受明確更新。手動編輯視窗不再因新訊息而關閉，已輸入的文字也不會被刷新清掉。

### 流暢度

- 角色資料快取、增量重播及只複製變更人物，減少重掃整段歷史。
- 卡片按資料變更更新，人物詳細欄位在展開後才建立。
- 同一應用的連續刷新合併，非同步刷新不重疊；關閉或隱藏的應用等重新顯示後再刷新，解鎖立即補上鎖屏期間的更新。
- 未讀數只更新角標，不因此重畫整個桌面；臺詞解析使用有大小上限的快取。
- **玉符設定 → 流暢模式** 預設開啟，減少毛玻璃、動態桌布與裝飾動畫。語音播放、聊天與生圖功能保留。

### 靈石

| 品級 | 對應下品靈石 |
|---|---:|
| 1 下品 | 1 |
| 1 中品 | 100 |
| 1 極品 | 100000 |

即 **1 極品 = 1000 中品；1 中品 = 100 下品**。只有這三種品級。轉帳／紅包可選品級；萬寶閣價格也可填 `2 中品靈石`，混合金額如 `1極品 2中品 3下品` 會精確換為 100203 下品。帳本保存下品值，重試同筆交易不再扣款。新交易以整數下品結算，原有小數餘額、待收款及退款仍精確保留原值，不在升級時乘以匯率。

第三方模型、語音及圖片服務的真實費用／額度照原單位顯示；它們不是劇情靈石。詳見 [靈石與舊帳相容](docs/SPIRIT-CURRENCY.md)。

## v0.9 操作方式

### Instagram 角色帳號、貼文與限時動態

Instagram 從目前對話的角色、狀態資料、聯絡人與手機事件建立帳號清單；選擇角色後，可要求該角色發文、發限動或回覆私訊。人物資料沿用同名聯絡人與正文設定，不從無關角色卡猜測身分。貼文支援喜歡、評論及圖片，限動支援回覆；限動在 24 小時後歸入歷史，不因重新整理延長。

正文裡的 Instagram 貼文、限動與私訊同步到手機。手機內的新內容也會顯示在主對話，讓後續正文讀取。

### 輸入框旁的「我」按鈕

酒館正文輸入框旁新增「我」按鈕。點開後選「我的資訊／我的物品／我的能力」，搜尋、查看描述並點選項目，即會在目前游標處插入引用；可繼續選取其他項目，再和正文一起送出。點選不會自動發訊息、扣款或消耗物品。

輸入 `@` 也能開啟快捷選單。可直接寫 `@我`、`@我的物品`、`@我的能力`，或 `@能力「時間停止」`；有重名時請用按鈕選取。按鈕插入的引用含使用者與穩定識別，送出前重新讀取目前資料，因此修改描述或改名後仍引用同一筆。已刪除或其他使用者的引用不會被當作仍持有的資產。

例如：先寫「我使用」，點「我 → 我的能力 → 時間停止」，再接著寫「救出車禍現場的人」。引用會在正文顯示成小標籤，模型取得對應已保存的效果說明。長期記憶仍正常提供背景；清單過長時會提供有標示的摘要，單獨選取可優先帶入該項細節。

### 手機外的訊息卡片

微信、Instagram、論壇與已確認購買會以專屬卡片呈現：微信氣泡、橘色轉帳、紅包、論壇標題與回覆，以及萬寶商城購物收據。正文中原本的手機內容在原位置繪製，前後敘事保留；多個事件可穿插在同一則回覆中。

小手機內連續的新操作合併為「手機動態」，每組最多 20 個事件，遇到新正文後另開一組。僅更新插件自己的、未經手動修改的活動組；來源識別避免重複同步。升級前已存為靜默記憶的紀錄不會大量補發，原有卡片與使用者修改會保留。商品搜尋、目錄生成及按讚不會產生購買收據。

「手機接入」可分別關閉論壇與商城購買的正文卡片，關閉期間仍保存記憶，重新開啟也不補發歷史紀錄。

使用者可直接輸入以下明確格式，單獨使用或穿插於同一段正文皆可：

```text
微信傳給林澈：「吃飯沒？」
Instagram私訊給林澈：「照片很好看。」
Instagram發文：「今晚的街景。」
Instagram發限動：「咖啡時間。」
論壇發文：「附近有推薦的咖啡館嗎？」
微信轉帳給林澈：520「晚餐錢」
微信紅包給林澈：88「好運」
```

角色回覆同樣可以將以下格式穿插於正文：

```text
微信傳給你：「吃飯沒？」
林知夏微信傳給我：「吃飯沒？」
林知夏在Instagram發限動：「散步」
林知夏微信轉帳給我：88.50「晚餐費」
林知夏微信紅包給你：20「好運」
```

例如：`我走進餐廳，微信傳給林澈：「吃飯沒？」接著找了個位置坐下，微信轉帳給林澈：88.50「晚餐費」，抬頭看向窗外。` 訊息與款項會在原來的位置變成卡片，前後正文保留。

角色指令未寫發送者時使用該則回覆角色；收件者「我／你／您」在這類角色指令中指使用者。一般小說敘述、引述、程式碼或狀態欄中的相同字樣不會被猜成操作。模型仍可用完整 `<phone>{...}</phone>` 協定表示手機活動；插件讀取原始資料，再繪製卡片。

**使用者從正文發出的轉帳、紅包先成為待確認付款。確認後才扣虛擬餘額。** 角色傳來的款項要領取後才入帳。穩定交易識別避免重播重複結算；已完成的交易不因刪除正文重新變成待領。

正文論壇貼文與回覆同步至原生論壇並記錄於記憶；明確的自然語法與有效的 forum 協定會在正文原位置繪製卡片。更新來源會修改對應內容；來源貼文刪除後隱藏，使用者留下的原生回覆仍保留，恢復來源時可重新顯示。相同來源重播不重複寫入或增加貼文。

### 小程式共用正文與世界書

「手機接入」可選手機文字模型連線及世界書。v0.9 移除原本 8 本、500 個啟用條目、單條 16000 字元與整體 48000 字元的世界書讀取拒絕限制。整本啟用條目會建立索引，搜尋包含大型條目後段及書本末尾；資料大小仍受裝置記憶體與酒館讀取能力約束。

世界書瀏覽器支援搜尋、分頁、閱讀條目完整內容與手動選取優先帶入的條目。生成時依本次任務及最近正文挑選相關內容，超長條目分段處理；停用條目不加入。每次生成重新讀取已儲存的世界書，巨集使用當前使用者與角色展開。

「世界書上下文預算」控制每次給模型的字元數，預設 48000，可自行調整；這是內容預算，不等於 tokens，也不會擴大模型服務的上下文容量。未放入當次上下文的條目仍可搜尋、閱讀與於其他任務調用。此讀取不模擬酒館的機率、遞迴或複合觸發規則；酒館原本的世界書觸發方式繼續運作。

微信、論壇、Instagram、日記、商城、通話與圖片提示詞整理共用接入。商城只使用相關劇情與個人設定；商品格式修復不接入角色、世界書或聊天。打開頁面、搜尋世界書及選擇預設不會呼叫模型。私密日記預設不分享，需在「手機接入」明確開啟後儲存。

手機中的微信、Instagram、交易狀態與已購物品會作為背景提供給正文。論壇歷史記憶與未購商品目錄只在明確查閱或命中具體貼文／商品名稱時調用。私密日記與 API 金鑰不作為公開手機活動。手機模型設定不會替換酒館主對話的連線。

### 檢視與修改角色狀態

在微信聯絡人資料卡，或角色頁的狀態入口，查看同名角色的 CSB21 狀態：身分、關係、衣著、心情、飽食度、飲水度等數值，以及身體部位內容。身高、體重、身材、外貌沿用明確角色卡或角色資料；未填欄位不擅自補值。

點「修改角色狀態」後可直接編輯。儲存會把新 CSB21 狀態快照寫入目前正文，手機與後續劇情都能讀取。後續狀態欄仍可按劇情更新，手動修改不會永久鎖死欄位。刪除、編輯或切換正文回覆後，狀態按目前對話重新計算。

既有 `CharacterStatus_WorldInfo.json` 與對應角色狀態正則繼續使用。此次更新的是手機配套，不替換你的角色狀態欄世界書。

### 圖片提示詞整理

長按微信圖片，或選「圖片選項 → 編輯圖片提示詞」，可更換該圖的 NovelAI 模型、預設、畫師串、正負面詞及場景。

新增「依劇情整理提示詞」：使用目前手機文字模型，結合正文、已選世界書及角色明確可見外貌，把場景整理成英文繪圖提示。成功後只填入場景欄位；畫師串、正負面詞、預設、模型及原圖片保留。這一步會呼叫文字模型，不呼叫 NovelAI 生圖；按「儲存並重新生成」才使用 NovelAI API。

同一草稿的重複點擊合併為一次整理。整理期間切換故事、編輯原圖設定或變更角色外貌，舊結果不套用到新資料。模型回傳無效內容會保留原草稿。

角色新傳送的描述型照片仍可自動使用已配置的 NovelAI 生成；微信生圖有獨立模型及預設選擇。歷史照片不會因更新或重新整理大量補生。生成成功才替換原圖，失敗保留原圖與重試入口。實際生成可能依 NovelAI 方案及參數消耗額度。

### 萬寶商城

原「劇情商城」改名「萬寶商城」，為使用者專屬的虛構商城。可查詢生活用品、人物／NPC、資格、身分、能力、槍支武器、世界觀中的違禁物及特殊道具，不要求品項已出現在劇情中，也不受故事年代的一般取得條件限制。

保留容錯讀取：模型把 JSON 包在說明或程式碼區塊、回傳商品陣列或明確金額字串時仍可解析。單件資料不合格不會讓其他有效商品一起丟失；截斷回覆中已完整結束的商品可保留，並顯示略過或截斷提示。只對 JSON 語法錯誤追加最多一次格式修復請求，不補造原回覆沒有的價格或效果。空白、拒答、連線失敗或無有效商品時保留原貨架。

v0.9 的商城搜尋增加「生成預設」選擇器與管理入口，可新增、編輯、刪除及匯入／匯出 JSON。內建「依目前世界」與「跨世界幻想」兩種方向；自訂預設用來控制商品類型、敘事風格與生成要求，最後仍套用固定的 JSON、虛擬價格及確認購買規則。支援本插件格式與可辨識的 SillyTavern 提示詞預設；不匯入金鑰或替換主對話模型。實際支援的欄位以匯入結果與提示為準。

預設無法保證模型供應商接受所有內容。空白或拒答不會被當成有效商品，也不會無限重試；可自行更換模型或預設後再次查詢。每次查詢顯示所用預設，與生成後再切換的設定分開記錄。

「手動新增商品」可自行填名稱、描述、虛擬價格及物品／能力分類，亦可編輯或下架，完全不需要模型請求。手動商品最多 64 件，重新生成時保留；每次模型結果最多 8 件。商品名稱最多 80 字元，價格 0.01–99999。手動新增不代表購買，仍需確認購買才扣款與加入「我」。這提供不依賴模型回覆的建立方式，插件不保證突破模型供應商的生成限制。

所選文字模型依需求與故事生成商品、價格、用途和劇情效果。查詢只生成貨架；在手機確認購買後才扣微信虛擬餘額並加入庫存。商品區分「物品」與「能力」：人物、資格與實體物件歸物品，直接取得的技能、異能、天賦與術法歸能力；教學書或道具仍可明確歸為物品。購買結果也寫入「我」的對應清單，供正文延續。

正文直接要求購買時，能明確對應目前貨架商品與價格，或由使用者明示價格的購買要求，才走既有訂單扣款流程；相同來源重播不重複扣款。正文描述取得了不在貨架上、未明確計價的物品或能力時，記錄為「正文取得／未計價」，不編造價格或追加扣款，能力依名稱與填寫描述接續，不自行增加未記載的冷卻、範圍或代價。查詢、購買意圖與已取得紀錄會分開判斷，模糊或尚未完成的敘述不當作已成交。

其他角色沒有商城入口，只有使用者主動告知才知道商城、訂單與取得來源。

這裡的查詢、人物、資格、交易和價格都是虛構故事資料，不是真實商家搜尋、交易或證照核發。

### 「我」、物品、能力與長期記憶

首頁的「我」集中管理「我的資訊」「我的物品」「我的能力」與「長期記憶」。資料依使用者名稱保存，切換對話或重新整理後仍保留；切換成不同名稱的使用者時，讀取該名稱對應的資料。商城購入及正文明確取得的紀錄可進入對應清單，日後也能在此檢視與整理。

長期記憶保存於插件設定，並提供有界限的背景內容給正文和手機文字模型；不要求另外綁世界書，也不會每次把所有內容無限制塞入模型。系統會在可用長度內提供相關與近期資訊，並保留名稱索引供辨識。使用者可選擇匯出或同步至專用世界書；自動同步預設關閉，開啟後才更新自己的記憶書，不會改寫其他既有世界書。

如需寫入世界書，打開「我 → 長期記憶 → 立即寫入世界書」。在正文輸入 `前面發生車禍了，我發現我現在需要特殊能力，我打開小手機，進入萬寶商城，購買了時間停止能力…` 會將時間停止能力加入「我的能力」，並在當次正文生成前提供給模型；沒有明確價格或既有商城售價時，只記錄取得、不扣款。

### 論壇與商城記憶

打開「我 → 長期記憶 → 論壇與商城記憶」，可搜尋本對話的貼文、回覆、曾上架商品和購買紀錄，並按來源篩選、展開完整紀錄、寫入世界書或匯出 JSON。此記憶跟隨目前對話保存；「我的資訊／物品／能力」則仍跟隨使用者名稱跨對話保存。更新會保留已歸屬本對話的論壇紀錄，並收錄 v0.7 商品清單；未標明來源的舊共用論壇內容不自動歸入新對話。

正文可說「回憶論壇之前的貼文」「查詢萬寶商城之前的商品紀錄」，或直接提到具體商品／貼文名稱。只取回相關紀錄作為背景，不追加手機卡片、不重播購買，不把未購目錄當作已擁有物品。世界書條目使用關鍵字觸發、非永久啟用；同步會保留世界書裡其他來源的條目。若希望酒館原生世界書也觸發這些條目，可自行綁定該記憶書；插件本身按需讀取不要求額外綁定。

介面一次列出最多 100 筆搜尋結果，正文每次最多取 20 筆、9000 字元；未列出的紀錄仍保存在聊天記憶，可縮小查詢後調用。手機動態紀錄共用上限為 20000 個事件，滿額會提示建立新對話，不靜默刪除舊紀錄。

## 正則、協定與儲存

內建協定與 `TavernPocket_Worldbook_v0.9.0.json` 內容一致。若改用綁定世界書管理協定，先關閉「手機接入 → 正文協定」，取消舊版協定書綁定，再綁定新書，避免重複或衝突指令。

正則 `TavernPocket_Regex_v0.9.0.json` 保留安全的文字備援顯示，插件執行時再繪製手機卡片。完整 JSON 原始紀錄仍用於同步，不刪除角色狀態欄、`<tts>` 或原版圖片。配套更新只處理本插件自己的規則與專用世界書。

v0.1／v0.2 原始聊天、手機 metadata 與舊擴充資料夾備份保留。舊私密日記沿用，已結算的舊金融事件作為歷史，不再入帳。新版使用原版全手機共用的虛擬錢包，舊版各對話餘額不累加；可在錢包自行修改餘額並保留流水。

原版聊天、論壇、媒體等存於目前瀏覽器 IndexedDB；新增 Instagram、日記與商品清單存於目前酒館聊天 metadata。正文活動與狀態編輯保存在酒館聊天；錢包、庫存及「我」的長期資料沿用擴充設定。備份酒館 data 目錄，並使用手機原版匯出／同步功能保存 IndexedDB 資料。清除瀏覽器網站資料會影響未匯出的手機內容。

付款去重以目前載入的手機及持久交易 ID 保護，並非跨多分頁的資料庫交易鎖；只在一個分頁操作錢包可避免並行修改。

## 驗證範圍

`tests/` 包含協定與自然語法、人物狀態、行內卡片與合併活動、論壇來源、Instagram、圖片預設與提示詞、商城物品／能力分類、記憶、交易重試與安裝器測試。瀏覽器測試使用 Chromium、IndexedDB 與實際手機 iframe；酒館宿主和模型回應以 fixtures 模擬，不使用你的金鑰或額度。最新完整驗證結果記錄於 `docs/VALIDATION.json`。

Android Termux 實機、你的文字／語音／生圖供應商以及跨裝置同步，需安裝後用實際環境確認。直接顯示的遠端圖片網址不等於已下載相簿資產；NovelAI 生成圖片會保存至手機相簿。
