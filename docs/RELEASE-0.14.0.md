# 傳音玉符 v0.14.0 · 內建 CSB v1.4.0

這次更新以小手機為唯一主插件。原有手機狀態資料與狀態欄規則保留，CSB 的角色庫、欄位與劇情面板也保留，並共用同一份角色資料。

## 已完成

- 角色管理可刪除角色，並可從「已刪除角色」還原。舊正文重播、換 ID 的 AI 更新及掃描不會自動復活已刪角色。
- 新增「目前在場／目前離場」。這個動作立即保存、恢復跟隨劇情；下一次明確劇情可改變它。原有固定在場、固定離場及跟隨劇情仍在。
- 購買、傳訊息、轉帳、貼文等手機操作留在手機及背景紀錄，不再新增正文訊息。舊手機收據僅隱藏顯示，原始聊天不刪除。
- @ 選單快取搜尋索引、合併輸入更新並重用結果節點，改善中文輸入、觸控、窄螢幕及手機鍵盤下的選單位置。
- CSB 提示處理出錯不再中止正文。普通敘事也能顯示既有狀態，正文重新繪製後會補回 CSB；其他狀態欄的 DOM 及事件不會整段重建。
- AI 掃描等待上限為 60 秒，取消立即停止等待；辨識空白、拒絕、格式與連線錯誤。空白、格式及暫時連線問題最多自動重試一次，拒絕與驗證失敗不重試。
- 內建 15 條完整配套世界書及正則，啟用或升級後自動匯入一次；「玉符接入」也能重新匯入。自訂條目、其他正則與原有狀態欄保留。

## 更新

已從 GitHub 安裝：在酒館擴充管理更新原本的 `tarven-pocket`，重新整理頁面。不要另外安裝第二份手機或 CSB。

離線／Termux／SillyDroid：執行本版 `TavernPocket_v0.14.0_Install.cjs`。安裝器辨識既有手機資料夾原地更新，保留 Git、自訂檔案及完整備份；需使用原本方式重啟酒館與重新整理。安裝包沿用原版本的 SillyTavern 1.19.0 支援門檻。

首次載入後會看到配套匯入結果。如宿主沒有世界書 API，畫面會說明原因，可使用 `presets/` 內 JSON 手動匯入。插件本身已注入協定，配套世界書匯入後不需再重複綁定。先前自行綁定的舊版配套世界書可在世界書選單取消勾選；不要關閉你的劇情世界書。

已安裝獨立 CSB 時，能識別且可安全釋放的副本會交由內建版本接管，角色資料不移除。無法識別的舊副本會顯示明確提示：停用舊獨立 CSB 再重新整理即可使用內建新版，不應同時執行兩份。

## 驗證與限制

單元測試涵蓋角色刪除／還原、即時在場、備份與保存失敗、掃描取消／空白／拒絕／重試、手機紀錄分流、配套保留與 @ 搜尋。另以隔離的酒館資料夾驗證一般安裝及 SillyDroid 升級、備份與失敗還原。具體數量見 `docs/VALIDATION-0.14.0.json`。

已使用真實 Chromium 執行手機與 CSB 的瀏覽器互動回歸；SillyTavern 事件、資料保存及模型回覆使用本機測試環境。尚未連接你的實機或付費模型。不承諾模型必定回覆：沒有加入破限、繞過審查或隱藏拒絕。SillyTavern 原生 `generateRaw` 不支援單次取消訊號，取消會忽略遲到結果，供應商請求仍可能繼續及計費。
