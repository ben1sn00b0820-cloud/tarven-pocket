## 角色信息

- 手動修改後連續加入兩則使用者訊息，未更新欄位完整保留。
- 局部更新情緒、人物離場，不清除身分與手動標記。
- 編輯／刪除／重抽原訊息不使手動資料失效；更晚明確更新仍能接續修改。
- 編輯表單輸入途中到達訊息事件，不自動關閉、不重置輸入。
- 空 set、未知空值不覆蓋已知值；明確 clear 與手動清空分開驗證。
- 正文開關關閉／重開，資料維持保存；插件卡片位於 `.mes_text` 內。
- 既有《玄衡界》備份 54 人／69 欄可驗證及匯入；原檔未放入程式倉庫。
- 頁面重載仍保留資料；作用域檢查防止切換聊天後寫到另一份存檔。

## 聯絡人

實際 UI 取消刪除不變更資料；確認刪除隱藏人物與私聊。再次同步舊正文及新提及均不自動恢復。舊 IndexedDB 訊息、人物資料與人設仍存在；手動恢復後可再次看見原聊天。資料快取測試連續 90 次讀取只進行一次原生 snapshot 投影，舊正文同長度編輯仍能正確失效。

## 靈石與歷史交易

- UI 選 2 中品轉帳，儲存 200 下品；選 1 極品紅包，儲存 100000 下品。
- 自然語法混合 `1極品 2中品 3下品` 精確得到 100203 下品，經正文同步也不再換算。
- 同付款／訂單識別重試不重扣、不重建訊息；新增品級 API 重試也有相同結果。
- 舊 12.34 轉帳精確入帳；拒收舊 45.67 不動餘額；舊 8.88 退回精確退款一次。
- `.34` 舊帳尾數與新整數交易並存，重載仍保留。
- 不合法品級與不完整混合金額不建立有效付款，不以部分數字或隨機紅包金額替代。
- 保留舊 JSON 輸出的 key 順序、ID、小數與固定字串，避免既有交易 fingerprint 改變。

## 手機布局與效能

手機整合覆蓋 430×932 及 360×800；角色信息、付款品級表單、聊天與輸入列量測橫向溢出均為 0 px。內嵌卡片的標題／說明對比約 15.51:1／7.20:1。CSB 單獨 UI 覆蓋 320、390、768、1280 像素寬度。

54 人／69 欄、250 則更新的資料重播測量：首次 33.19 ms，後續 100 次快取讀取合計 8.84 ms，沒有再次完整重播。這是資料引擎在測試環境的耗時，不是實際手機畫面幀率。刷新佇列另外覆蓋 100 次 burst、隱藏／恢復、非同步不重疊、不同 thread 合併、取消與失敗恢復。

完整瀏覽器回歸亦確認鎖屏期間的新訊息保存在資料庫，解鎖即補上畫面，不必等待另一個事件。應用操作的忙碌狀態在最後一次刷新完成後才解除，空查詢後重新輸入不會碰上尚未完成的重畫。

## 安裝與限制

離線安裝器在臨時目錄測試了舊擴充備份、聊天／配置不變、宿主 symlink 不變、重裝、版本不符、內容校驗與異常路徑。最終配套由 manifest 版本派生；不再執行會覆寫為 0.9.1 的舊 ZIP 工作流程。

瀏覽器執行真實插件、iframe、表單與 IndexedDB；SillyTavern APIs 和文字／圖片模型是測試替身。沒有使用使用者 API 額度，也沒有直接操作使用者的實體 Android／SillyDroid。程式無法從所有自然語言中可靠判斷欄位改動是否有敘事根據；提示要求模型只輸出有根據的局部更新，程式另外阻止無意義的清空。已刪除且無備份的資料不能憑空恢復。
