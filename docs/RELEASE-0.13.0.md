# 傳音玉符 0.13.0：角色庫與劇情時間

內建角色信息維持 **CSB 1.2.1**，包含上一版「未生成正文仍阻擋掃描」的修補。

## 正文顯示與角色庫

舊版 TTS 把臺詞另外包成可播放內容；當正文已經寫過同一句，再附上 TTS 臺詞時，畫面可能顯示兩次。本版清理舊 TTS 顯示與重複臺詞，移除正文聲波按鈕，**不改寫聊天儲存的原始正文**。

移除本插件的 TTS 配音、音訊播放、聽取及相關設定。「聲律譜」改為「角色庫」，保留角色新增、編輯與人物資料；「靈樞」改為「接入設定」，提供文字及圖片服務設定；「法式集」改為「規則集」。既有角色資料可繼續使用。

千里傳音、浮光錄、論道臺、萬寶閣、吾身錄、修行札記、圖片及其他玉符應用繼續保留。

## 劇情時間

首頁日期與時鐘改為讀取目前聊天的劇情時間，不再顯示裝置現在的時間，也不會按現實分鐘自行往前走。缺少資料時顯示「劇情時間未設定」。

點選首頁日期／時間區塊，或控制中心的「劇情時間」，即可填寫「劇情日期」「劇情時刻」並按「儲存」。例如日期可填「天元三年霜月十五」，時刻可填「子時」或「23:30」。這項設定只屬於目前聊天；按「跟隨劇情」即可清除手動設定。

自動讀取先採用 CSB 的 `scene.time`，沒有 CSB 時間時，再讀正文中獨立一行的明確標記：

```text
劇情日期：天元三年霜月十五
劇情時間：子時
```

也支援單行 `劇情時間：天元三年霜月十五 子時` 或 `場景時間：夜間`。只有當新的正文標記出現在 CSB 時間來源之後，且 CSB 快照仍與該來源一致時，才以新標記更新顯示；手動修改或匯入的 CSB 時間仍優先。

保留原來的曆法與時段文字，不擅自換算公曆。臺詞中的日期、明日計畫、引用、程式範例及隱藏推理不會被當成目前時間。切換聊天、編輯、重抽或刪除訊息後，依目前保留的內容重新讀取。

## 更新

以完整 0.13.0 程式更新既有擴充，保留聊天與使用者資料。更新後重新整理酒館，再開啟「傳音玉符 → 玉符接入 → 安裝／更新配套規則」，確認配套為 **v0.13.0**。內建 CSB 維持 **1.2.1**；已另外安裝獨立 CSB 的使用者仍以獨立版本為優先，請保留其 1.2.1 修補。

版本化配套為 `presets/TavernPocket_Regex_v0.13.0.json` 與 `presets/TavernPocket_Worldbook_v0.13.0.json`。它們沿用既有玉符事件協定及正則識別碼，安裝時更新原規則，避免重複新增。
