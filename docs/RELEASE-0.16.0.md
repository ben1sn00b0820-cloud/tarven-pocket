# 傳音玉符 v0.16.0 · 三種世界與獨立 AI 填表模型

本版由 v0.15.0 更新，內建角色資訊 CSB v1.6.0。保留既有角色、欄位、模板、聊天、商城、物品與錢包資料。

## AI 填表模型

- 角色信息 → AI 填表 → AI 填表模型：可選「沿用酒館目前模型」、酒館 Connection Manager 已儲存的連線，或小手機已儲存的自訂文字模型。
- 萬寶閣／萬寶商行／購物商城：查詢欄下方直接選擇「AI 填表模型」。也可保留原本「沿用小手機文字模型」的行為。
- 兩個功能各自記住選擇，不會切換正文使用的模型，也不會改動另一個功能的選擇。
- 自訂 API：接入設定 → 文字模型 → 自定義介面，新增並儲存地址、模型和金鑰。模型列表支援讀取，也可手填模型名稱。已儲存且具地址與模型名稱的介面會出現在填表選單中，即使小手機的整體文字來源仍設為酒館也能選用。
- 模型與提示預設分開選。角色的自訂介面會收到掃描補充指示、輸出格式和所選正文；選用酒館連線時，「沿用酒館預設」使用該連線保存的預設。角色的「沿用酒館目前模型」保留原有獨立抽取／完整酒館預設兩種路徑。
- API Key 沿用原本獨立金鑰儲存，不放進模型選單、掃描預設或一般設定。
- 已刪除的模型會明確提示重新選擇，不會偷偷改走另一個模型。角色掃描仍先預覽，由你勾選套用。

## 隨時切換世界

在手機底部的設定 App → 世界模式選擇；App 名稱會隨模式顯示為玉符設定、手札設定或手機設定。切換立即生效，並隨酒館設定保存。

| 模式 | 裝置／通訊 | 社群／論壇 | 商城／錢包 | 貨幣 |
|---|---|---|---|---|
| 現代 | 小手機／微信 | Instagram／論壇 | 購物商城／錢包 | 元（亦可選百元、萬元輸入） |
| 古風 | 隨身手札／飛鴿傳書 | 浮生錄／茶館 | 萬寶商行／錢袋 | 文銅錢、兩銀子、兩金子 |
| 修仙 | 傳音玉符／千里傳音 | 浮光錄／論道臺 | 萬寶閣／靈石袋 | 下品、中品、極品靈石 |

- 古風為遊戲設定：1 兩金子 = 10 兩銀子，1 兩銀子 = 1000 文銅錢。
- 修仙沿用原比例：1 極品 = 1000 中品，1 中品 = 100 下品。
- 新交易的記帳單位依序是元、文銅錢、下品靈石，使用整數。舊有精確小數尾數保持原值。
- 切換模式保留帳面數字，不進行跨世界匯率轉換。例如餘額 520 在現代是 520 元、古風是 520 文銅錢、修仙是 520 枚下品靈石。商城售價同樣保留數字。
- 系統介面、內建禮物名稱、貨幣換算和 AI 生成提示一同切換；你寫的正文、商品名稱、角色資料與自訂提示詞不會被批次改字。
- 歷史正文中的明確靈石／金銀價格按原單位解析，避免重新同步時誤換金額。
- 商城生成期間若切換模式，舊請求結果會被丟棄，保留既有商品。請在新模式重新生成。

## 安裝

本次提供離線安裝器與完整原始碼。GitHub 使用者可在酒館擴充功能管理頁更新原本的 `tarven-pocket`，更新後重啟酒館並重新整理。

### Termux

下載 `TavernPocket_v0.16.0_Install.cjs` 至手機 Download 資料夾後執行：

```bash
node ~/storage/downloads/TavernPocket_v0.16.0_Install.cjs
```

若尚未授予 Termux 儲存空間權限，先執行 `termux-setup-storage`。找不到酒館時，在命令最後指定原本 SillyTavern 的資料夾。安裝器會辨識原擴充資料夾、建立備份並原地更新。完成後依原本方式重啟酒館並重新整理頁面。

### 手動／GitHub

解壓縮原始碼 ZIP，把 `tarven-pocket` 內檔案覆蓋原擴充資料夾，或上傳到你的原倉庫後再由酒館更新。勿在原擴充內再套一層 `tarven-pocket`。CSB 已內建於 `companions/csb-character-state`，不需另外安裝副本。

配套規則位於 `presets/TavernPocket_Worldbook_v0.16.0.json` 與 `presets/TavernPocket_Regex_v0.16.0.json`，可在「接入」頁面安裝／更新。世界模式規則會由插件每輪提供，世界書中的修仙範例不改變所選模式。
