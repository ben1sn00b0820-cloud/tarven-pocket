# 傳音玉符 0.15.0 · CSB 1.5.0

AI 填表新增可保存的掃描預設、沿用酒館目前提示預設的生成方式，以及男女分開的角色欄位。小手機仍是唯一主插件；原有狀態欄和內建 CSB 保留。

## AI 填表預設

從「角色信息 → AI 填表」選取預設：

- **標準抽取 · 獨立提示**：沿用目前模型連線，以專用抽取提示分析選取正文，保留既有預設行為。
- **沿用酒館目前預設**：透過酒館的安靜生成流程，使用當前提示預設；酒館可能同時加入角色卡、世界書和歷史，因此上下文用量可能較大。填表結果仍必須有選取正文中的原文依據。
- **自訂掃描預設**：可新增、複製、編輯、刪除和匯入／匯出；每份保存生成方式、補充提示和選填的回應額度。選擇會保存，自動 AI 掃描也使用該選擇。

掃描預設是 `CSB_SCAN_PRESETS` 格式，不是酒館模型連線或提示管理器的匯出檔。要使用其他酒館提示預設，先在酒館選好，再選「沿用酒館目前預設」。不會自行切換模型或修改酒館的預設。

填表不送出輸入框草稿，也不增加正文回覆。結果先供核對；自動採用仍受原本設定控制。保留拒絕、逾時、取消與格式錯誤處理。安靜生成請求如果在逾時後仍未結束，會暫時阻止再次送出同類掃描，避免重複請求。

## 通用、女性、男性模板

在「欄位模板」切換通用、女性、男性範圍；每個欄位可指定適用模板。角色會顯示通用欄位，加上相符模板的專屬欄位。舊欄位預設為通用，不會突然消失。

角色編輯器可選擇「自動依性別」或手動指定模板。自動選擇只讀取明確的性別資料，不從姓名或外貌猜測；未知時使用通用模板。切換模板保留原值與鎖定，重新切回可繼續使用。AI 掃描及正文更新也會檢查欄位適用性。

## 介面與配套匯入

重新整理角色管理、欄位編輯和掃描畫面的層級、間距與手機版佈局。新增控制保留原有刪除／還原、目前在場／離場及固定在場設定。

配套安裝不再只相信舊版完成記錄，會檢查世界書和正則。針對缺少世界書 context 方法的環境加入相容讀寫路徑，保存後檢查內容；失敗會顯示原因並保留重新匯入入口。這些修正針對程式中確認的失敗路徑，未取得使用者裝置的錯誤紀錄。

「玉符接入 → 世界書與正則」會顯示狀態，並提供重新匯入和兩份 JSON 的個別下載。

## 手動匯入

1. 在酒館「世界書」匯入 `TavernPocket_Worldbook_v0.15.0.json`。
2. 在「擴充功能 → 正則」匯入 `TavernPocket_Regex_v0.15.0.json`。
3. 若同時留下舊版傳音玉符配套正則，停用舊版，只啟用新版；保留其他正則與原本狀態欄規則。
4. 重新整理酒館。插件已提供協定提示，配套世界書不必再重複全域啟用；自己的劇情世界書照常使用。

配套世界書是手機與 CSB 的操作協定；先前的「百姝紀」世界觀檔案不被取代。
